# DSD leadership development: completed local scope

The owner authorized full development within DSD before any wider agency expansion. This pass builds three substantive starting points: self-directed aspiring leaders; people encouraged by colleagues or supervisors; current leaders strengthening practice. Every entry has an original explanation, three or four observable learning objectives, a DSD example, and three linked next steps. No nomination or service threshold applies to this learning experience.

A shared development map connects an aspiration with one of six DEIA capabilities, existing experience, a real opportunity, support/access, feedback, evidence of growth, and a return point. Optional after-practice questions distinguish a proposal from what was tried and learned. Notes are held separately for each starting point while the page is open. Maps can be copied or downloaded. They are not submitted, ranked, or treated as appointments.

The ten-stage employee-life-cycle experience remains the first shared learning area. Pathway links now open the relevant stage directly. The existing succession tool serves as the organizational counterpart to the personal map: critical work, needed capability, opportunity, support, transfer, and a readiness check. The page adds concrete mentoring, sponsorship and feedback guidance, and preserves One DHS/DSD resource connections.

Scope remains DSD. No agency-wide expansion, production deployment, live publication, external messages, or staff-data collection occurred. There is no claim that a course completion proves readiness or that a plan guarantees an opportunity or promotion.

The second-agent review identified the missing differentiation between audiences and a cross-path validation issue. Both were addressed and functionally tested. Twelve tests passed without skips; TypeScript and scoped lint passed. Browser work verified paths, preserved notes, capability choice, after-practice reflection, copying, file download and stage navigation. Nineteen linked destinations passed with saved receipts.
