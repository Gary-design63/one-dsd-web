# Cover image briefs: DSD Service System course series

Authoring record for Gary Banks and the program builders. September 19, 2026. Internal authoring and verification guidance under `docs/MULTIMEDIA-AUTHORING-STANDARD-2026-09-09.md`.

This record covers the thirteen program-authored courses in `lib/content/courses/authored/dsd-practice/` (index numbers 1181 to 1193). Each course needs one photorealistic cover photograph. None has been authored yet. Each course's cover path is reserved on disk and seeded with a copy of a topically close, already approved program photograph, so the course surfaces render and the tests pass now, and so that delivering the final photograph is a file replacement at the same path with no code or data change.

## What is and is not done

| State | Meaning |
| --- | --- |
| Reserved | The path in `public/images/covers/` exists and the course and `plan.json` reference it. |
| Seeded | The file at that path is a copy of an approved photograph named below, chosen for topical closeness. It is an interim reuse, recorded here as an explicit reuse decision. |
| Authored | Not yet. No new photograph has been generated, purchased, or produced for any of the thirteen courses. |
| Verified | The alt text is in place and matches between the course pack and `plan.json`; `tests/authored-courses.test.ts` confirms the file exists. Nothing about the final photograph has been checked, because it does not exist. |

Delivering a final photograph: write it to the reserved path, keep the alt text unless the scene changed, and record the generation or source provenance and rights status in this file.

## Shared direction for all thirteen

- Photorealistic, natural proportions, believable skin and fabric, plausible Minnesota light and setting, coherent hands, faces and eye-lines. Match the quality of the existing approved e-learning photographs; do not repeat one group composition across the set.
- Landscape, at least 1600 pixels wide, close to a 3:2 or 16:9 ratio, to match the existing covers. Portrait images do not fit the tile.
- Fictional people in fictional scenes. Nothing in a caption or on the page presents them as real staff or real people served.
- Disability is represented across the set as it is in the Division's caseload: mostly nonvisible, sometimes visible. Across the thirteen, one scene includes a wheelchair user, one a person with Down syndrome, one a hearing aid, one a communication device; the rest show people whose disability is not signaled by appearance, equipment or costume. A wheelchair is not the default symbol. Nobody is posed to look disabled.
- No person, garment, symbol or organization stands for a whole community. Subjects across the set vary in age, race, body and setting without any one image carrying that variation alone.
- The person served is the subject of the scene and is doing something, not being done to. Staff are present in service of that.
- No logos, screens with readable text, or documents with readable content. Paper and devices appear as objects.
- The alt text below is the accessibility alternative and is already in the course pack and `plan.json`. It describes what is in the frame in a sentence; it does not diagnose anyone.
