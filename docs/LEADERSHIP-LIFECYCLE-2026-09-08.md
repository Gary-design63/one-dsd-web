# DEIA leadership through the employee life cycle

Owner direction, September 8, 2026: first leadership-development slice is DEIA across the employee life cycle, with reflection, learning, potential leaders, existing leaders and concrete succession planning. Keep connected with the whole One DHS program and apply examples to DSD. Local preview authorized; no deployment requested.

## Learning design
Ten stages: role/posting design; recruitment; assessment/interview; orientation; everyday support; mentoring/sponsorship/development; advancement; retention; succession/continuity; transition/departure. Each stage contains a question, learning explanation, fictional DSD scenario, practical steps, reflection prompt, proposed evidence and an existing resource link.

The repeating sequence is learn, reflect, practice, return. Cultural context should broaden interpretation, never diagnose an individual from identity. The interview scenario separates observation, inference and job-related evidence.

The three development entry points are exploring leadership, leading a team, and preparing for broader responsibilities. They share the DEIA lens; this is not a generic management curriculum or a promotion guarantee. No minimum service requirement applies to this voluntary local learning experience. Formal institutes and vacancies retain their own requirements.

## Tools
Reflection builder: optional learning note, required practice, optional follow-up; creates copyable/downloadable text. Changing stages clears the draft and all inputs; the interface explains this before use.
Continuity builder: critical work, capabilities, open development opportunity, support, usable knowledge transfer, readiness evidence, and follow-up. No employee ranking, nomination or automated personnel decision. Optional unanswered commitments remain explicitly to be agreed.
Both use ephemeral page state. No submission, external message, database write or calendar creation.

## Program connections
Linked from the existing One DHS leadership area, One DSD Team and orientation. Connects to learning, practice, equity in operation, ASK, ERGs, Amplify mentoring and the Learning Lab.
