Read PRD.html and TRD.html for the product and technical handoff. README.md documents local setup. Use Node.js24.x and npm11.9.0, run npm ci, copy .env.example to .env.local and supply only the settings appropriate to your environment, then npm run dev. This archive includes the actual application source, original and added public media, transcript JSON, pinned local search model, migrations, tests, and safe configuration template.

SOURCE-MANIFEST.json lists every source input and SHA-256. The final release receipt is in evidence/multimedia-review-2026-09-09/final-release-receipt.json. No credentials, staff work records, installed dependencies, or production database are included. Historical corpus forensic checks requiring private source bytes need separately authorized local fixtures; see README.md.

The separate local second-brain workspace is not installed by this archive. This source handoff does not bypass its outstanding import restriction.
